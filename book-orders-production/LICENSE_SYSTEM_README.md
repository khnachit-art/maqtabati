# نظام مفاتيح الترخيص (License Key System) - Maqtabati

## نظرة عامة

تم إضافة نظام ترخيص كامل لتطبيق Maqtabati يسمح للمطور بإنشاء مفاتيح ترخيص فريدة لكل زبون، والزبائن يدخلون التطبيق فقط بمفتاحهم الخاص.

---

## 🔑 كيف يعمل النظام

### للمطور (أنت):
1. **تسجيل دخول كمسؤول** → الذهاب إلى `/license`
2. **إنشاء مفتاح جديد** → ملء بيانات العميل (اسم، بريد، شركة، تاريخ انتهاء، حدود الاستخدام)
3. **المفتاح يتولد تلقائياً** → صيغة: `XXXX-XXXX-XXXX-XXXX-XXXX-XXXX`
4. **إرسال المفتاح للزبون** → عبر الإيميل أو واتساب

### للزبون:
1. **يدخل على رابط التطبيق** (مثلاً: `https://maqtabati.com`)
2. **يظهر له صفحة دخول بمفتاح الترخيص**
3. **يضع مفتاحه** → يضغط "دخول"
4. **إذا صحيح** → يدخل التطبيق مباشرة، المفتاح يُحفظ في المتصفح
5. **الزيارات اللاحقة** → يدخل مباشرة دون إعادة إدخال المفتاح

---

## 📋 مميزات النظام

| الميزة | الوصف |
|----------|-------|
| **توليد مفاتيح آمنة** | 24 حرف عشوائي (128-bit entropy)، بدون حروف مربكة (I,O,0,1) |
| **صلاحية محددة** | تاريخ انتهاء اختياري (أو غير محدود) |
| **حدود استخدام** | مستخدمين، مدارس، كتب كحد أقصى |
| **حالات المفتاح** | نشط، منتهي، ملغي، معلق |
| **تتبع الاستخدام** | يسجل كل دخول (IP، وقت، متصفح) |
| **حفظ محلي** | المفتاح يُخزن في localStorage للدخول التلقائي |
| **حماية الصفحات** | كل الصفحات محمية ما عدا `/login` و `/api/license/validate` |

### 3. تشغيل التطبيق

## 🔐 API Endpoints

### GET `/api/license`
قائمة المفاتيح مع فلترة وتقسيم صفحات
```json
{
  "licenses": [...],
  "pagination": { "page": 1, "limit": 20, "total": 5, "totalPages": 1 }
}
```
Query params: `status`, `search`, `page`, `limit`

### POST `/api/license`
إنشاء مفتاح جديد
```json
{
  "customerName": "مدرسة الاختبار",
  "customerEmail": "test@school.com",
  "companyName": "مجموعة مدارس",
  "expiresAt": "2026-12-31",
  "maxUsers": 5,
  "maxSchools": 10,
  "maxBooks": 1000,
  "notes": "مفتاح تجريبي"
}
```

### GET `/api/license/[id]`
تفاصيل مفتاح واحد + سجل الاستخدام

### PUT `/api/license/[id]`
تحديث المفتاح (يمكن تغيير الحالة، التمديد، الحدود...)

### DELETE `/api/license/[id]`
إلغاء المفتاح (soft delete: يغير الحالة إلى `revoked`)
مع `?hard=true` للحذف النهائي

### POST `/api/license/validate`
**نقطة الدخول للزبائن** - تحقق من المفتاح
```json
// Request
{ "key": "ABCD-EFGH-IJKL-MNOP-QRST-UVWX" }

// Response (success)
{
  "valid": true,
  "license": {
    "customerName": "مدرسة الاختبار",
    "companyName": "مجموعة مدارس",
    "maxUsers": 5,
    "maxSchools": 10,
    "maxBooks": 1000,
    "expiresAt": "2026-12-31T00:00:00.000Z"
  }
}

// Response (failed)
{ "valid": false, "error": "انتهت صلاحية المفتاح" }
```

- **نموذج إنشاء/تعديل** في نافذة منبثقة (Modal)
- **أزرار إجراءات**: تعديل، إلغاء
- **توليد مفتاح تلقائي** عند الإنشاء

## 🔒 حماية الصفحات

تم إضافة `LicenseGuard` في `layout.tsx` يغلّف كل المحتوى:
1. يتحقق من `localStorage` للمفتاح المحفوظ
2. يرسل للمصادقة عبر `/api/license/validate`
3. إذا صحيح → يظهر المحتوى
4. إذا غير صحيح/منتهي → يحذف المفتاح وينقل لـ `/login?redirect=...`
5. بعد تسجيل الدخول الناجح → يعيد التوجيه للصفحة المطلوبة

الصفحات المستثناة (عامة):
- `/login`
- `/api/license/validate`
- `/api/auth/*`
- الملفات الثابتة (`/_next/*`, `/favicon.ico`, `/logo.png`)

```
5. 🔄 الزيارة التالية: يدخل مباشرة (المفتاح محفوظ)

```

## 🛡️ أمان

- **مفاتيح غير قابلة للتخمين**: 24 حرف من 32 رمز = 2^128 احتمالات
- **لا تظهر في URL**: ترسل عبر POST body
- **تسجيل الاستخدام**: كل تحقق يسجل (IP، User-Agent، وقت)
- **انتهاء تلقائي**: يتحول للحالة `expired` تلقائياً عند التحقق
- **إلغاء فوري**: المطور يمكنه إلغاء أي مفتاح فوراً من لوحة التحكم

## 📝 خطوات تسليم مفتاح لزبون جديد

1. ادخل `/license` كمسؤول
2. اضغط **"إنشاء مفتاح جديد"**
3. املأ:
   - اسم العميل (مطلوب)
   - الإيميل/الهاتف (للتواصل)
   - الشركة (اختياري)
   - تاريخ الانتهاء (اختياري - اتركه فارغاً لغير محدود)
   - الحدود (مستخدمين/مدارس/كتب) - القيم الافتراضية تناسب معظم الحالات
   - ملاحظات (داخلية)
4. اضغط **"إنشاء المفتاح"**
5. انسخ المفتاح من الجدول (يظهر بالتنسيق: `XXXX-XXXX-XXXX-XXXX-XXXX-XXXX`)
6. أرسل للزبون عبر الإيميل/واتساب مع رسالة:
   ```
   مفتاح ترخيصك لتطبيق Maqtabati:
   
   XXXX-XXXX-XXXX-XXXX-XXXX-XXXX
   
   ادخل على: https://your-domain.com
   ضع المفتاح واضغط دخول.
   المفتاح صالح حتى: YYYY-MM-DD (أو "لا ينتهي")
   ```

## 🔧 استكشاف الأخطاء

| المشكلة | الحل |
|----------|-------|
| "مفتاح غير صحيح" | تأكد من نسخه كاملاً، لا مسافات زائدة |
