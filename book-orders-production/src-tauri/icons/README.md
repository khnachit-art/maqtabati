# Icons Directory

Place the following icon files here:

- `icon.ico` - Windows icon (256x256, 128x128, 64x64, 48x48, 32x32, 16x16)
- `icon.icns` - macOS icon
- `32x32.png` - 32x32 PNG
- `128x128.png` - 128x128 PNG
- `128x128@2x.png` - 256x256 PNG (for retina)

You can generate these from the logo.png using:
- https://icoconvert.com/ (for .ico)
- https://iconverticons.com/online/ (for .icns)
- Or use: `npx tauri icon logo.png` (Tauri CLI)
